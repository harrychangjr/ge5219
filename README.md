# ge5219: code written by Harry

In this branch, Harry drafted selected notebooks which explores the historical weather data from National Environmental Agency in Singapore.

- "Rainfall EDA 2020-2024.ipynb" - explores historical rainfall (2020-2024) in Singapore, although eventually these weren't used in our final Transit Comfort Dashboard
- "Weather Discomfort 2024 EDA.ipynb" - aggregates air temperature, humidity, wind speed, wind direction, rainfall data from 2024 into a single dataset, before visualizations measuring weather discomfort were eventually plotted and used for our Transit Comfort Dashboard

Visualisations relating to weather discomfort can be found on our homepage (historical analysis section): https://sites.google.com/view/ge5219-transitcomfort
